# Run 009 - 2026-06-19

## Setup

- Started from the main menu with the latest mod already installed/running.
- Run: unseeded couch co-op, 4 player slots.
- Characters: Ironclad, Silent, Defect, Necrobinder.

## Result

Unplayable roadblock on Act 1, floor 2, immediately after all four players voted into the first monster node.

The final map vote response was `Final couch map vote received; travel queued to Monster at (4,1)`. After travel, all four slots reported:

- `state_type: monster`
- `shared.state_type: monster`
- `message: Combat ended. Waiting for rewards...`
- `battle: null`
- `rewards: null`

The state was unchanged after waiting 5 seconds.

## Flow

- Ironclad: Initial choice script failed to select a Neow option because it produced a blank choice. Later recovered by explicitly choosing Phial Holster, receiving Gigantification Potion and Skill Potion.
- Silent: Chose Scroll Boxes and completed bundle selection, but later still showed initial Neow options and could choose Arcane Scroll as a second Neow reward.
- Defect: Chose Arcane Scroll and reached Neow done/waiting state.
- Necrobinder: Chose Lava Rock and reached Neow done/waiting state.

After manual recovery, all four slots reported `state_type: map`. All four submitted successful map votes for the monster at `(4,1)`, then the run entered the stuck post-combat/pre-reward state.

## Issues And Quirks

- Slot 1 could receive Scroll Boxes, complete its bundle, then later choose a second Neow reward (Arcane Scroll). This indicates a per-slot Neow completion/state reset bug.
- Slots 2 and 3 reported `waiting_for_all_players: true` while slots 0 and 1 were still in initial Neow states. Repeated `proceed` on slot 2 returned `Waiting for the other local players to finish the event`, which was accurate but did not identify which slots were unfinished.
- The first-combat blocker reproduced again after all four slots were on map and all four map votes succeeded. The final vote message used `travel queued`, not `traveling`.

## Recovery Tried

- Explicitly chose Neow options for unfinished slots 0 and 1.
- Verified all four slots returned to map.
- Waited 5 seconds after the stuck combat state; no change.
