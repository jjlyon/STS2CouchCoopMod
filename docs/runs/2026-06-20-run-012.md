# Run 012 - 2026-06-20

## Setup

- STS2 was already running with the latest installed mod.
- Run: unseeded couch co-op, 4 player slots.
- Characters: Ironclad, Silent, Defect, Necrobinder.

## Result

Unplayable roadblock on Act 1, floor 2, immediately after all four slots voted into the first monster node.

All four slots reported `state_type: monster` with `Combat ended. Waiting for rewards...`, but no battle, rewards, event, card-selection, card-reward, or map state was available. The players were all alive, and no combat payload was exposed.

## Flow

The run began with an Ancient node at floor 0, which opened Neow.

- Ironclad: Chose Precise Scissors, then removed a Strike from the card-removal prompt.
- Silent: Chose Fishing Rod.
- Defect: Chose Hefty Tablet, selected Adaptive Strike from the rare-card choice, then confirmed the selection.
- Necrobinder: Chose Nutritious Oyster, raising max HP to 77.

After all follow-up prompts resolved, all four slots reported Neow with `can_proceed: true`. Sending `proceed` returned all slots to map. No slot returned to the initial Neow reward menu or gained a second Neow relic.

The party chose the middle first-monster path at `(3,1)`, which led toward an Unknown node after the fight. All four slots voted successfully, and the final response queued travel to the monster. The state then landed in the combat-ended limbo blocker rather than a live battle.

## Issues And Quirks

- Reproduced the first-combat limbo blocker again: every slot saw `state_type: monster` and `Combat ended. Waiting for rewards...` with no actionable state.
- The first failed attempt to choose Neow options used an unsupported JSON field (`option_index` instead of `index`) and returned blank responses without changing state. Retrying with `index` worked. This is a harness-driver mistake, not a mod issue.
- `proceed` responses after slot 0 were blank, but the action still completed and all slots reached map.

## Fix Validation Notes

- Multiple Neow reward grab did not reproduce.
- Precise Scissors card removal worked and did not cause a second reward offer.
